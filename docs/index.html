github-docs-cli

하나의 GitHub 저장소를 문서 도구로 사용하세요. 이슈·디스커션·위키, 그리고 GitHub Pages로 발행되는 docs/ 폴더를 AI 에이전트와 자동화가 다루기 위한 가볍고 의존성 없는 CLI입니다. Turn a single GitHub repository into a documentation tool. A small, dependency-free CLI for AI agents and automation to manage issues, discussions, the wiki, and the docs/ folder behind GitHub Pages.

Go · 0 dependencies REST + GraphQL JSON output Linux · macOS · Windows JHL License · non-commercial
$ curl -fsSL https://jhl-labs.github.io/github-docs-cli/install.sh | sh
$ github-docs-cli note add --kind decision --title "Use Go" --body "Single static binary."

왜 필요한가Why

에이전트의 기록은 코드 옆에 있어야 합니다. An agent's record belongs next to the code.

개발 노트·연구 노트·의사결정을 외부 도구에 흩어 두는 대신, 이미 쓰는 GitHub 저장소에 남기세요. github-docs-cli는 인증·재시도·Pages/Contents 처리를 일관되게 감싸, 에이전트가 hook 한 줄로 결정 사항을 기록하고 문서 트리를 안전하게 관리하게 합니다. GitHub.com과 Enterprise Server를 모두 지원합니다. Instead of scattering dev notes, research, and decisions across external tools, keep them in the GitHub repo you already use. github-docs-cli wraps auth, retries, and the Pages/Contents plumbing so an agent can record a decision in one hook call and manage the doc tree safely. Works with GitHub.com and Enterprise Server.

기능Features

에이전트 친화적으로 설계됨Designed for agents

이슈 · 디스커션Issues & discussions

이슈를 문서/노트로 다루고, 디스커션은 GraphQL로 생성·조회·댓글. Treat issues as documents/notes; create, read, and comment on discussions via GraphQL.

docs 폴더 · Pagesdocs folder & Pages

Contents API로 docs/ 파일을 읽고/쓰고, GitHub Pages 발행까지 제어. Read/write docs/ files via the Contents API and drive GitHub Pages publishing.

위키 관리Wiki management

<repo>.wiki.git를 클론해 페이지 목록·조회·작성·삭제. Clones <repo>.wiki.git to list, read, write, and delete pages.

노트 hookNote hook

note add로 개발/연구/의사결정 노트를 로그 파일·이슈·디스커션에 기록. note add records dev/research/decision notes to a log file, an issue, or a discussion.

워크플로우 · 스킬 생성Workflow & skill generators

generate-workflow로 Pages 배포 워크플로우, generate-skill로 에이전트 스킬 문서 생성. generate-workflow emits Pages workflows; generate-skill emits agent skill docs.

견고한 호출Resilient calls

429/5xx·secondary rate limit에 지수 백오프 재시도, Retry-After 존중. Exponential-backoff retries on 429/5xx and secondary rate limits, honoring Retry-After.

주의Heads up

토큰과 권한Tokens & scopes

본문은 GitHub-Flavored Markdown입니다. 인증에는 GITHUB_TOKEN(또는 GH_TOKEN)이 필요하며, 이슈/콘텐츠/Pages에는 repo, 디스커션에는 write:discussion 권한이 필요합니다. wiki 명령은 git 바이너리가 있어야 합니다. Bodies are GitHub-Flavored Markdown. Authentication needs GITHUB_TOKEN (or GH_TOKEN); use the repo scope for issues/contents/pages and write:discussion for discussions. The wiki commands require the git binary.
